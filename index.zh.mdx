## 什么是 NimBuild Starter？

NimBuild Starter 是一个**生产级 AI SaaS 模板**，专为快速启动商业化 AI 产品而设计。包含完整的用户认证、订阅计费、积分系统、AI 工具工作区、管理后台、营销页面、文档站和国际化支持。

### 核心特性

- **用户认证** — Firebase Google 登录与安全服务端会话
- **积分计费** — 按次计费的积分系统 + 可审计的积分账本 + 订阅计划（Stripe 支付）
- **AI 工具工作区** — 基于火山引擎的小红书文案生成，包含积分扣除和生成历史
- **管理后台** — 用户管理、积分调整、订阅控制
- **国际化** — 完整的中英文支持（next-intl）
- **邮件系统** — Resend 交易邮件
- **营销页面** — 首页、定价、博客（MDX）和法律页面

### 技术栈

| 层级   | 技术                                    |
| ------ | --------------------------------------- |
| 框架   | Next.js 16 (App Router) + React 19      |
| 样式   | Tailwind CSS + Framer Motion + Radix UI |
| 数据库 | PostgreSQL + Drizzle ORM                |
| 认证   | Firebase Auth                           |
| 支付   | Stripe                                  |
| AI     | 火山引擎 OpenAI-compatible API          |
| 邮件   | Resend                                  |
| 国际化 | next-intl                               |
